# Defect Formation Energy Analysis

This script automates the calculation of defect formation energies by comparing defective and pristine systems. It accounts for differences in atomic composition and net charge between the two structures to evaluate the defect formation energy.

## Features

- Automated calculation of defect formation energies from AIMPRO output files.
- Handles changes in stoichiometry and charge state.
- Supports finite-size linear scaling to extrapolate formation energies to the dilute limit.
- Automates application of the Freysoldt–Neugebauer–Van de Walle (FNV) charge correction scheme.
